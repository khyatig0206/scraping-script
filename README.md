**Justdial Doctor Scraper**
Built a **Python + Node.js web scraping system** to extract **doctor details and clinic information** from **Justdial**. Used **Puppeteer** and **Cheerio** to collect profile links, then automated **API-based data extraction** using **Requests** and **MongoDB** for storage. Implemented **multi-step scraping**, **data cleaning**, and **dynamic pagination** to gather verified profiles efficiently.

**Tech Stack:** Python, Node.js, Puppeteer, Cheerio, Requests, MongoDB

**Highlights:**

* Automated collection of 100+ doctor profiles with full details (name, clinic, reviews, contact).
* Combined browser automation and API scraping for accuracy and scalability.
* Designed modular, extendable architecture for future healthcare data scraping.
